Flow under review

Reviewers should be able to see the chain clearly before opening the live chat.

1. Guided discovery

Sam asks targeted requirement questions and stops when it has enough context instead of endlessly prompting.

2. PRD generation

The workflow switches into generate mode and returns a structured markdown PRD plus a quality score.

3. Email handoff

The PRD is converted to markdown binary and sent through the email approval path after a wait-form resume.

4. Jira creation

After explicit approval, the workflow extracts the first Epic, FR, and TC and creates the Jira hierarchy.

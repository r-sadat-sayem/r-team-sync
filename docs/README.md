## Current Documentation Model

- The docs in `docs/` describe the **current live system first**.
- Focused root-level docs still exist for presentation and operations.
- `CLAUDE.md` and `AGENTS.md` are contributor/agent instructions, not the main product or architecture documentation.

## Status Labels Used Here

- **Active**: used today in the working flow
- **In progress**: implemented partially or not yet the primary path
- **Demo-only**: useful for presentation or review, but not the core backend logic
- **Planned**: design intent only, not the live system
